# TRAE CLI Sidebar

在 VS Code 右侧辅助边栏中使用 TRAE CLI。使用 TRAE app-server，参照 Codex 的会话、任务和执行事件交互方式独立实现；没有复制 Codex 扩展的编译代码或品牌素材。

## 安装

需要 VS Code 1.104+，以及支持 `traecli app-server --stdio` 的 CLI（本机验证版本为 0.208.1）。

1. 安装 TRAE CLI。插件会自动检查登录状态；未登录时点击“去登录”，在 VS Code 终端完成官方登录流程，成功后自动刷新会话列表。也可自行运行 `traecli login`，然后点击“我已登录，重新检测”。
2. 扩展面板右上角 `…` → “从 VSIX 安装”，选择 `traecli-sidebar-0.14.9.vsix`，更新后重载窗口。
3. 打开并信任项目，点击编辑器顶部右侧 TRAE 图标。关闭辅助边栏后，顶部入口仍可使用。

未打开文件时，可运行命令 `TRAE CLI: Open Chat`。辅助边栏可通过“视图 → 外观 → 辅助边栏”显示。工具栏被隐藏时检查 `workbench.editor.editorActionsLocation`。

## 本版优化

- Mode 同行右侧增加权限选择：默认权限、只读、项目内编辑、完全访问。只能在当前任务未运行时修改，并从下一个任务开始生效；任务运行中会锁定入口并提示该任务仍按启动时权限运行，避免误以为已动态提权。各会话独立保留；默认权限使用打开该会话时的 CLI 设置。只读禁止写入和网络访问；项目内编辑在沙箱外操作时按需授权；完全访问允许文件和网络访问并关闭授权询问。

- 任务审批按 app-server 请求类型显示真实选项：命令和文件操作提供“允许一次”“本会话允许”“拒绝并继续”“拒绝并停止”；额外文件或网络权限提供“允许本任务”“本会话允许”“拒绝”。只有 CLI 明确提供命令或网络规则提案时才显示“允许并记住”选项。普通审批不会暗中切换 Auto 或完全访问模式。

- 移除 Service Tier，改为模型 Mode。根据 CLI 的模型变体目录显示 Standard / Max，发送真实的 `modelBackendVariant`；各模式的上下文窗口显示在菜单中；只有一个 Mode 时仍可展开查看上下文窗口，没有 Mode 信息时才隐藏入口。切换 Mode 时同步检查其支持的 Reasoning Level，历史恢复和并行会话独立保留模式。


- 输入框操作栏增加 Reasoning Level，选项来自当前模型的真实目录；选择后传入下一次请求的 `effort` 参数，各会话独立保存。切换模型会使用新模型的默认等级，不支持调节的模型隐藏 Reasoning Level 入口。

- 优化会话列表层级：独立的新建入口、正在进行/最近会话分组、状态标签、简洁时间及当前会话标记。刷新时保留列表的键盘焦点。
- 聊天顶部显示会话名称，收起正常连接提示；空输入禁用发送，查看旧消息时提供“回到最新”入口。统一主题色、间距和悬停反馈，兼容窄侧栏及浅色主题。

- 会话界面左上角 `←` 返回项目会话列表。返回、切换或新建会话不会停止原任务，可以同时运行多个会话；列表显示各会话的执行阶段及“等待授权”状态。
- 输出、草稿、模型、附件和权限请求按会话隔离；右下角终止按钮只停止当前显示的会话。后台等待授权时，点击对应会话进入处理。

- 未登录或登录失效时显示登录引导，保留草稿。登录过程自动检测状态，最多持续 10 分钟；取消或失败后可重试。CLI 缺失、配置错误和连接失败分别保留错误提示，不会误显示成空会话列表。

- 打开侧边栏先展示当前项目的历史会话，按更新时间排序，支持刷新和分页；点击会话进入聊天，顶部 `新会话` 新建。只展示目录与当前项目一致的会话，重载后不再自动进入上次会话。
- 各会话分别保留输入草稿，返回列表不会中断当前任务，可通过“返回正在处理的会话”继续查看。
- 执行阶段与耗时（如“执行命令 · 45秒”）位于输入框上方的独立状态行，不占用输入框内部的操作栏。
- 热门模型进入服务端队列时，同一状态行显示模型负载、排队状态、队列位置和累计等待时间，例如“模型负载 92% · 排队中 · 队列第 3 位 · 40秒”；排队完成后自动切换到模型处理或工具执行状态。有效排队通知会延长任务启动等待时间，避免把正常长队列误判为连接超时。
- `/compact` 的上下文压缩队列使用独立生命周期和最长 10 分钟等待，不会把普通任务误标成执行中，也不会在压缩结束后锁住输入框。
- 模型自动路由或回退时显示原模型、备用模型、重试和最终结果；回退失败会明确显示，不再静默使用不同模型。


- 流式正文实时排版 Markdown，按动画帧更新收到的文字。已完成段落保持原有 DOM；正在生成的列表、代码块和段落局部更新，结束时无需切换为另一套排版。


- 生成中的回复显示光标，区分思考与回复阶段；首段内容立即更新，后续片段按帧合并。部分模型或后端可能延迟首段，插件不会模拟未收到的内容。


- 发送按钮位于输入框内右下方，任务处理时在原位置切换为终止按钮，结束后恢复发送。模型选择列表在模型按钮上方展开，支持方向键、Escape 关闭及点击外部关闭。


- 初始化失败后可重新尝试；连接断开、失败或请求超时时，输入框上方显示“重新连接”，重建连接并恢复会话和草稿，正常时隐藏。不会自动重发模型任务，避免重复执行。
- 发送失败自动恢复草稿和附件；原用户气泡标记“发送失败 · 内容已恢复到输入框”，避免误认为请求已被模型接收。新输入也会保留。草稿和模型选择保存到当前工作区，附件仍保存在内存中。
- 加载历史或恢复会话期间锁住发送；旧进程事件被隔离。启动超时时显示“状态待确认”，需重连后确认任务状态。
- 顶部“变更”或工具行的文件按钮打开 VS Code 原生左右对比。仅在补丁与当前内容精确匹配时重建修改前内容，否则显示原始补丁；审阅不会改写文件。
- 点击上下文标签预览内容，点击 `×` 移除；输入 `@` 可搜索项目文件。上下文总长度默认限制为 200,000 字符，超限时保留输入供调整。
- 显示连接状态、执行阶段和耗时；首个回复片段立即刷新，后续流式输出按 16ms 合并并只传递变化的消息。聊天 DOM 最多显示 200 条，可分页查看更早的消息；控制器最多保留 500 条、约 8 MB 的消息内容，单条正文、工具详情和补丁也有上限。
- 复制回复使用 VS Code 剪贴板 API，工具状态显示中文。

## 交互

- 输入框固定在底部，左右留白为 6px，默认显示两行文本，随内容自动调整高度；Enter 发送，Shift+Enter 换行，支持中文输入法。
- `＋` 添加文件上下文；有选中代码时优先添加选区。附件以可移除的标签显示，发送前可检查。
- 右键编辑器 `TRAE CLI: Send Selection` 添加文件位置和代码片段。
- 模型按钮从 CLI 获取真实模型目录，选择后在下一次发送时生效并保存；恢复会话时显示 CLI 返回的实际模型。
- 回复流式显示，支持 Markdown；命令、输出、文件修改补丁以可展开的工具行显示。文件按钮打开变更审阅。
- 请求命令、文件、额外目录或网络权限时显示范围和原因，并按协议提供单次、任务、会话、拒绝后继续或拒绝并停止等适用选项；兼容旧版审批请求。MCP 表单请求使用 VS Code 原生输入框确认，链接请求只有在用户明确允许后才会打开。权限选择会修改下一个任务的沙箱与授权策略；app-server 不支持在当前任务中途替换完整权限配置。
- 右下方按钮在任务处理时显示 `■`，点击请求中断任务，收到服务端完成事件后恢复发送。
- 左上角 `←` 返回当前项目的会话列表，支持分页和继续对话。CLI 保存真实会话；每次重载后先展示列表，由你选择要继续的会话。
- 顶部 `新会话` 新建会话，已有任务继续在后台运行；不会删除历史会话。

多根工作区当前使用第一个文件夹。添加文件最大 100,000 字符，超出时请选择片段；未保存的编辑器内容也会作为附件发送。诊断见“输出 → TRAE CLI”。远程开发需在远程扩展宿主环境安装并登录 CLI。

## 实现与边界

Codex 公开的 CLI、app-server、SDK 可参考：[官方说明](https://developers.openai.com/blog/codex-as-a-platform)、[App Server 文档](https://learn.chatgpt.com/docs/app-server)、[IDE 交互说明](https://learn.chatgpt.com/docs/codex/ide)。本机 Codex 扩展包的许可指向 OpenAI 使用条款，没有声明其界面为可复用开源代码。

本项目使用 TRAE CLI 本机生成的协议类型（`src/protocol`），独立编写 JSON-RPC 连接与界面。界面由 VS Code 主题变量控制，不是 Codex UI 的完整复制。

尚未实现 Codex 的全部功能：图片附件、执行中消息队列、逐块接受/撤销修改、云任务和多工作区选择。原生 diff 是只读审阅，不是修改前审批；侧栏只缓存最近 500 条消息和 500 个会话摘要，更早内容仍由 CLI 保存，可通过重新打开真实会话恢复。

并行会话在当前 VS Code 窗口中保活；以 6 个可立即切换的会话运行时为软上限，超过后回收最早且无任务、授权、草稿或附件的闲置进程，稍后可从历史重新连接。活跃任务和未发送内容不会为满足上限而被强制清理。重载窗口或退出 VS Code 会关闭这些连接；差异预览的虚拟文档缓存最多保留 40 份并在扩展释放时清空。

app-server 被 CLI 标记为实验性接口，不同 CLI 版本可能需要更新协议。动态工具、账户令牌刷新和设备证明等需要宿主能力的请求会返回明确的协议错误，绝不默认批准；额外文件/网络权限、MCP 表单和旧版命令/补丁审批已接入。历史恢复会重新连接真实 CLI 会话，但对插件关闭时仍在运行的任务恢复能力尚未做完整验证。

## 开发与验证

可配置 `traecli.maxContextCharacters` 调整总字符限制。模型上下文容量与字符数不是一回事，此限制不代表精确 token 预算。

```sh
npm install
npm run check
npm test
npm run build
npm run package
```

F5 打开 Extension Development Host。浏览器界面检查（需要本机 Google Chrome）运行 `node tests/chat.test.mjs`，生成 `docs/chat-preview.png`。协议与控制器测试验证重试、历史恢复、并发锁、失败草稿恢复、授权、中断、增量同步与精确补丁还原。浏览器测试验证窄侧栏、左上角返回入口、会话切换后的草稿和输出隔离，以及长对话分页。运行 `npm run test:host` 启动隔离 VS Code 扩展宿主，用模拟 CLI 验证两个会话同时运行、授权和停止隔离，以及真正的原生 diff 编辑器；不会修改日常 VS Code 的配置。非 macOS 可用 `VSCODE_EXECUTABLE` 指定 VS Code 可执行文件，用 `CHROME_PATH` 指定 Chrome。

输入框下方仅显示本会话累计 Token 用量，不显示「本会话」标签。数字按 K（千）、M（百万）、B（十亿）、T（万亿）缩写，最多保留两位小数，悬停可查看完整数字；收到 CLI 的用量通知时立即刷新，不按定时轮询更新。切换会话时显示对应会话的用量，后台会话独立记录。尚未返回用量数据时显示「—」，不会根据文本估算 Token。

输入框以 `/` 开头时，在输入框上方显示侧栏命令列表，随输入过滤。支持 ↑/↓ 或 Ctrl+P/Ctrl+N 移动、Enter/Tab 选择、Esc 关闭、鼠标点击。模型、Mode、推理等级、权限和技能的二次选择也使用同一个列表，继续输入可过滤选项。

侧栏内置命令：`/model`、`/mode`、`/reasoning`、`/permissions`、`/skills`、`/new`、`/clear`、`/history`、`/review`、`/compact`、`/status`、`/init`、`/help`。模型和技能从 CLI 查询；选择技能后成为可移除的附件，随下一条请求以原生 skill 参数发送。`/compact` 调用 CLI 上下文压缩接口；`/init` 提交检查项目并创建或更新 AGENTS.md 的任务。`/clear` 开始一个新会话并保留旧历史。未知命令不会作为普通消息误发。此列表包含已接入侧栏的操作，不包含终端专用或自定义 Markdown 命令。

连续的思考、计划和工具调用合并为默认折叠的「思考与工具调用」区块，仅显示步骤数和执行状态。点击展开后可逐项查看摘要、输出和文件变更；流式更新保留展开状态。模型的最终回复直接显示，权限确认仍单独显示。

发送后立即显示折叠的执行过程占位，不再等待首个推理或工具事件。折叠行按任务阶段显示「正在启动」「排队中」「模型处理中」「思考中」「调用工具 XXX」或「生成回复中」，并显示旋转指示和轻微文字呼吸效果；真实步骤优先，事件间隙由当前任务阶段兜底。只有当前回合的最新过程组显示动画，旧计划不会抢占指示器；等待授权和任务完成时保持静态。模型没有返回可展示摘要时，完成步骤显示为不可展开的「思考 · 已完成」，不会出现空白详情。遵循系统减少动态效果设置。
